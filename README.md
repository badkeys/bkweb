# bkweb

This repository contains the backend code for the dynamic parts of the [badkeys.info](
https://badkeys.info) web page. The static content is maintained in [a separate
repository](https://github.com/badkeys/badkeys.info).

The `wsgi` dir contains the actual code, to run this needs to be configured for the
`/check/` path on the host.
